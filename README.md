# city-salon

Entity 스택(ES/AS/www) 기반 프로젝트. [ehfuse/project-template](https://github.com/ehfuse/project-template) 을 기반으로 시작했다.

개발 규칙은 `AGENTS.md` 를 단일 출처로 사용한다.

| 경로 | 역할                        |
| ---- | --------------------------- |
| www/ | 사용자 웹 (React + Vite)    |
| as/  | Entity App Server (Fastify) |
| es/  | Entity Server (예정)        |
